# 스터디아자스

`index.html`을 더블 클릭하면 브라우저에서 바로 실행됩니다. 설치, 로그인, API 키가 필요 없습니다.

- 기초 수학 / 국어 문해력 선택
- 2문제 레벨 테스트: 모두 맞히면 실력 쑥쑥, 그 외에는 기초 탄탄 단계
- 수준에 맞는 5문제와 오답 시 쉬운 말 힌트
- 학습 완료 시 연속 출석 저장 (같은 날은 한 번만 증가)
- 하루 이상 빠진 경우 쉬운 수학 1문제로 다시 시작

`app.js`에 문제와 학습 로직, `style.css`에 화면 디자인이 있습니다. 힌트는 미리 저장한 문장을 사용하며 실시간 AI를 호출하지 않습니다. 문제는 과목과 단계별로 고정되어 있습니다.

학습 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 같은 기기와 브라우저에서 사용해 주세요. 브라우저 데이터를 삭제하면 기록도 사라집니다. 파일 직접 실행 시 브라우저 설정에 따라 저장이 제한될 수 있습니다.
